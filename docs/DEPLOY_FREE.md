# פריסה חינמית של תזרים (תמיד ברשת)

המטרה: האתר חי גם כשהמחשב כבוי — **בלי לשלם**.

משתמשים בשני שירותים חינמיים:

| חלק | שירות | מחיר |
| --- | --- | --- |
| האפליקציה | [Render](https://render.com) Free | ₪0 |
| מסד הנתונים | [Neon](https://neon.tech) Free | ₪0 |

> בלי Neon הנתונים נמחקים כש־Render נרדם. לכן חובה לחבר את שניהם.

## מגבלות (חינם)

- אחרי ~15 דקות בלי כניסה האתר נרדם
- הפתיחה הראשונה אחרי שינה יכולה לקחת כ־דקה
- עדיין **כתובת קבועה** באינטרנט, בלי המחשב שלך

---

## שלב 1 — Neon (מסד נתונים)

1. היכנס ל־https://console.neon.tech והירשם (חינם)
2. צור פרויקט חדש (למשל `tazrim`)
3. העתק את **Connection string**  
   נראה בערך כך:  
   `postgresql://user:pass@ep-xxxx.aws.neon.tech/neondb?sslmode=require`

---

## שלב 2 — Render (האתר)

1. היכנס ל־https://dashboard.render.com עם GitHub
2. **New → Blueprint**
3. בחר את הריפו `lotto-intelligence-israel` (ענף `main` אחרי המיזוג, או הענף שלך)
4. Render יזהה את `render.yaml`
5. לפני Deploy הגדר משתני סביבה:
   - `DATABASE_URL` = מחרוזת החיבור מ־Neon (הדבק כמו שהיא)
   - `APP_PUBLIC_URL` = אפשר להשאיר ריק קודם, ואז לעדכן לכתובת ש־Render נותן  
     למשל `https://tazrim.onrender.com`
6. לחץ Deploy והמתן לסיום הבנייה

---

## שלב 3 — בדיקה

1. פתח את הכתובת ש־Render נתן
2. התחבר: `sahar` / `sahar1234!` (או המשתמשים שיצרת)
3. כבה את המחשב — האתר אמור להמשיך לעבוד מהטלפון

---

## טיפים

- אחרי הדיפלוי הראשון: בהגדרות השירות ב־Render עדכן `APP_PUBLIC_URL` לכתובת האמיתית
- אם האתר “ישן” — פשוט חכה כ־דקה בפתיחה הראשונה
- אל תשים סיסמאות בקוד; רק ב־Environment של Render
