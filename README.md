# תזרים — מעקב השקעות שותפים

דשבורד בעברית (RTL) למעקב אחרי משקיעים, מסלולים עם אחוז חודשי קבוע, תשלומים, עמלת ניהול והצעות למשקיעים חדשים.

## התחברות

אין כניסת אורחים. התחברות ב־**שם משתמש + סיסמה**.

| הרשאה | מה רואים |
| --- | --- |
| משקיע | רק את הנתונים שלו |
| מנהל | הכל + התראות + הצעות + משתמשים |

מנהל ברירת מחדל:

| שם | שם משתמש | סיסמה |
| --- | --- | --- |
| סהר | `sahar` | `sahar1234!` |

איפוס סיסמה ללקוח — רק דרך המנהל (מסך משתמשים). אין איפוס עצמי במייל.

## גישה מכל מקום ומכל מכשיר

### אפשרות מומלצת כרגע — קישור ציבורי מיידי

מריצים מנהרה מאובטחת (Cloudflare) ומקבלים קישור `https://...trycloudflare.com`
שנפתח מכל טלפון / מחשב / רשת:

```bash
chmod +x scripts/share-public.sh
./scripts/share-public.sh
```

הקישור נשמר ב־`.public-url`. **לא מחליפים אותו** כל עוד המנהרה חיה —
`share-public.sh` לא פותח מנהרה חדשה אם כבר יש קישור שמור / תהליך רץ.
רק עם `FORCE_NEW_TUNNEL=1` אפשר ליצור קישור חדש במפורש (משנים ללקוחות).

התחברות מנהל: `sahar` / `sahar1234!`

> הקישור חי כל עוד תהליך `cloudflared` רץ. אל תעצרו אותו אם כבר עדכנתם לקוחות.

### אפשרות קבועה חינמית — Render + Neon (מומלץ)

האתר חי ברשת גם כשהמחשב כבוי, **בלי תשלום**:

ראה מדריך מלא: [`docs/DEPLOY_FREE.md`](docs/DEPLOY_FREE.md)

בקצרה: Neon Free למסד נתונים + Render Free לאפליקציה (`render.yaml`).

### אפשרות קבועה בתשלום קטן — דיסק ב־Render

```bash
docker compose -f docker/docker-compose.prod.yml up --build -d
```

ואז מעלים את ה־`Dockerfile` ל־Render Starter (~$7/חודש) עם דיסק קבוע.

### באותה רשת Wi‑Fi בלבד

```bash
./scripts/start-production.sh
```

- מחשב: http://localhost:8000  
- טלפון באותה רשת: `http://<IP-של-המחשב>:8000`

## מה יש באפליקציה

- **לוח בקרה** — קרן, תשלומים, עמלות, התראות כניסה
- **משקיעים ומסלולים** — קרן, אחוז חודשי, משך
- **תשלומים** — דוח שנתי קלנדרי + PDF
- **הצעות** — מפרט חודשי + PDF למשקיע חדש
- **משתמשים** — שמות משתמש, סיסמאות, בקשות איפוס
